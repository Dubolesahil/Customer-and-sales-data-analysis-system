# Customer and Sales Data Analysis System

## Project Overview
A data analytics project that analyzes customer and sales data to understand business performance, identify profit and loss areas, and generate actionable insights.

## Objectives
- Analyze total sales, profit, and quantity sold.
- Identify top-performing product categories and sub-categories.
- Compare sales across customer segments and regions.
- Analyze discounts and profitability.
- Create visualizations to communicate business findings.
- Generate data-driven business recommendations.

## Tools and Technologies
- Python
- Pandas
- Plotly
- Google Colab
- Jupyter Notebook

## Key Performance Indicators (KPIs)
- Total Sales
- Total Profit
- Total Quantity Sold
- Average Discount

## Analysis and Visualizations
- Category-wise Sales Analysis
- Sub-category Profit and Loss Analysis
- Customer Segment Analysis
- Region-wise Sales and Profit
- Monthly Sales Trends (if date data is available)

## Project Files
- `sales_analysis.ipynb` — Analysis notebook, if included
- `business_insights_report.csv` — Business summary
- `cleaned_sales_data.csv` — Cleaned dataset
- `category_performance.csv` — Category performance
- `subcategory_profit_loss.csv` — Sub-category profitability
- `region_performance.csv` — Regional performance
- `business_recommendations.csv` — Recommendations

## How to Run
1. Open the notebook in Google Colab.
2. Upload the required sales dataset.
3. Run the notebook cells in order.
4. Review the visualizations and exported reports.

## Business Value
This project demonstrates how data analysis can help businesses evaluate sales performance, investigate losses, and identify opportunities to improve profitability.
